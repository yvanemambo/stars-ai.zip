Télécharger l'appli Android

Le fichier de l'appli (1,9 Mo), pour les téléphones Android.

Télécharger pour Android
  1. Touche Télécharger pour Android.
  2. Quand le téléchargement est fini, ouvre le fichier STARS-AI.apk.
  3. Si le téléphone affiche « Pour votre sécurité… », touche Paramètres, active Autoriser cette source, puis reviens en arrière.
  4. Touche Installer, puis Ouvrir.

L'avertissement est normal pour une appli qui ne vient pas encore du Play Store. YvanAI ne demande aucune autorisation spéciale : le micro et l'appareil photo ne servent que quand tu les touches.

Sur iPhone

  1. Ouvre stars-ai.onrender.com dans Safari.
  2. Touche le bouton Partager (le carré avec une flèche vers le haut).
  3. Choisis Sur l'écran d'accueil, puis Ajouter.

YvanAI apparaît alors sur ton écran d'accueil, comme une appli.

Ouvre cette page dans Chrome

Tu es dans le navigateur de WhatsApp ou de Facebook, qui bloque parfois les téléchargements. Touche les ⋮ en haut à droite, puis Ouvrir dans Chrome (ou « Ouvrir dans le navigateur »).
