Installer YvanAI sur Android

Installe la version actuelle de YvanAI directement depuis Chrome. Le nom et l'icône affichés seront ceux de YvanAI.

  1. Ouvre cette page dans Google Chrome.
  2. Touche le menu ⋮ en haut à droite.
  3. Choisis Installer l'application ou Ajouter à l'écran d'accueil.
  4. Confirme l'installation de YvanAI.

Si l'ancienne application Stars AI est encore installée, désinstalle-la d'abord pour éviter de garder son ancienne icône.

Sur iPhone

  1. Ouvre yvan-ai.onrender.com dans Safari.
  2. Touche le bouton Partager (le carré avec une flèche vers le haut).
  3. Choisis Sur l'écran d'accueil, puis Ajouter.

YvanAI apparaît alors sur ton écran d'accueil, comme une appli.

Ouvre cette page dans Chrome

Tu es dans le navigateur de WhatsApp ou de Facebook, qui bloque parfois les téléchargements. Touche les ⋮ en haut à droite, puis Ouvrir dans Chrome (ou « Ouvrir dans le navigateur »).
